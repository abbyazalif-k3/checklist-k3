CHECKLIST K3 TAMBANG - V3
Isi sudah diterapkan dari 3 formulir:
1. Elution Area
2. Mill #3 dan Scat Crusher
3. Reagent Mixing Area

Cara pasang ke GitHub Pages:
- Upload index.html, manifest.json, sw.js ke repository checklist-k3.
- Pastikan branch utama dan folder /(akar).
- GitHub Pages: Settings > Pages > Deploy from a branch > branch utama > /(root) > Save.
- Buka URL GitHub Pages Anda.

Catatan penyimpanan:
Data inspeksi tersimpan di localStorage browser/perangkat. Artinya data tetap di HP/browser yang dipakai, bukan otomatis tersimpan ke GitHub atau database online.
Gunakan 'Arsip Semua Data' untuk menyimpan salinan JSON.
